Building a **GitHub Actions repo** is the right technical move: GitHub gives you free cloud compute (Linux runners), scheduled cron triggers, and git-based persistence, completely freeing you from keeping a PC running.

### System Architecture Overview

```
                      [GitHub Actions Cron Runner]
                       (Every Friday at 16:00 IST)
                                   │
                                   ▼
             1. Download Live Master & Technical Data (yfinance/Bhavcopy)
                                   │
                                   ▼
             2. Apply Hard Filters:
                • Price Band: ₹100 <= CMP <= ₹950
                • Liquidity: 20-Day Avg Volume >= 500,000 shares
                • Trend Regime: CMP > 50-DMA > 200-DMA
                • Anti-Downfall: 1M (20d) & 2M (40d) ROC > 0%
                • Proximity: Within 15% of 52-Week High
                                   │
                                   ▼
             3. Compute Composite Momentum Score (CMS):
                CMS = (0.50 * 3M_ROC) + (0.30 * 52W_Prox) + (0.20 * Vol_Ratio)
                                   │
                                   ▼
             4. Extract Rank #1 Winner & Calculate Zerodha GTT Parameters:
                • Initial Stop (-7%)
                • Milestone 1 Target (+15%) & Ratchet (+2.5% Breakeven Lock)
                • Milestone 2 Target (+30%) & Ratchet (+15.0% Profit Lock)
                                   │
                     ┌─────────────┴─────────────┐
                     ▼                           ▼
        [Commit `signals/latest.json`]   [Push Alert: Telegram / Discord]

```

#### 2. `src/engine.py`

```python
import os
import io
import json
import requests
import numpy as np
import pandas as pd
import yfinance as yf
from datetime import datetime

CAPITAL_BASE = float(os.getenv("CAPITAL_BASE", "1000.0"))
MIN_PRICE = 100.0
MAX_PRICE = 950.0
MIN_AVG_VOLUME = 500_000

def get_broad_nse_universe():
    """Fetches broad market active NSE symbols dynamically."""
    url = "https://raw.githubusercontent.com/datasets/investor-flow/master/data/nifty500.csv"
    try:
        df = pd.read_csv(url)
        return [f"{s.strip()}.NS" for s in df['Symbol']]
    except Exception:
        # Fallback list of top liquid names across mid/small caps
        return ["BEL.NS", "TATAPOWER.NS", "BHEL.NS", "ASHOKLEY.NS", "FEDERALBNK.NS", "NMDC.NS", "SAIL.NS"]

def evaluate_ticker(df, cmp):
    # Rule 1: Anti-Downfall Filter (Zero 1-month or 2-month negative bleed)
    roc_20 = (cmp - df['Close'].iloc[-21]) / df['Close'].iloc[-21]
    roc_40 = (cmp - df['Close'].iloc[-41]) / df['Close'].iloc[-41]
    if roc_20 <= 0 or roc_40 <= 0:
        return None

    # Rule 2: Moving Average Structure (Stage 2 Uptrend)
    sma_50 = df['Close'].rolling(50).mean().iloc[-1]
    sma_200 = df['Close'].rolling(200).mean().iloc[-1]
    if not (cmp > sma_50 > sma_200):
        return None

    # Rule 3: 52-Week High Proximity (Within 15%)
    high_52w = df['High'].iloc[-250:].max()
    dist_52w = (cmp - high_52w) / high_52w
    if dist_52w < -0.15:
        return None

    # Rule 4: Volume Liquidity
    avg_vol_20 = df['Volume'].rolling(20).mean().iloc[-1]
    if avg_vol_20 < MIN_AVG_VOLUME:
        return None

    # Calculate Composite Momentum Score (CMS)
    roc_60 = ((cmp - df['Close'].iloc[-61]) / df['Close'].iloc[-61]) * 100
    prox_score = (1 - abs(dist_52w)) * 100
    vol_ratio = (df['Volume'].iloc[-5:].mean() / df['Volume'].iloc[-50:].mean()) * 10

    cms = (0.50 * roc_60) + (0.30 * prox_score) + (0.20 * vol_ratio)
    return cms, high_52w, roc_60

def main():
    symbols = get_broad_nse_universe()
    data = yf.download(symbols, period="1y", interval="1d", group_by="ticker", threads=True, progress=False)

    candidates = []
    for sym in symbols:
        try:
            df = data[sym].dropna()
            if len(df) < 220:
                continue

            cmp = float(df['Close'].iloc[-1])
            if not (MIN_PRICE <= cmp <= MAX_PRICE):
                continue

            res = evaluate_ticker(df, cmp)
            if res is None:
                continue

            cms_score, high_52w, roc_60 = res
            shares = int((CAPITAL_BASE - 20) // cmp)  # Reserve ₹20 buffer for taxes & DP charges
            if shares < 1:
                continue

            candidates.append({
                "symbol": sym.replace(".NS", ""),
                "cmp": round(cmp, 2),
                "cms_score": round(cms_score, 2),
                "roc_3m": f"+{round(roc_60, 2)}%",
                "shares_to_buy": shares,
                "capital_required": round(shares * cmp, 2),
                "initial_stop": round(cmp * 0.93, 2),       # -7% Hard Stop
                "m1_target": round(cmp * 1.15, 2),         # +15% Target
                "m1_ratchet_stop": round(cmp * 1.025, 2),  # +2.5% Breakeven Lock
                "m2_target": round(cmp * 1.30, 2),         # +30% Target
                "m2_ratchet_stop": round(cmp * 1.15, 2)   # +15% Profit Lock
            })
        except Exception:
            continue

    os.makedirs("data/signals", exist_ok=True)
    out_file = "data/signals/latest.json"

    if not candidates:
        payload = {
            "status": "CASH",
            "timestamp": datetime.utcnow().isoformat(),
            "message": "Market breadth weak. Zero stocks passed filters. Hold 100% Cash."
        }
    else:
        candidates.sort(key=lambda x: x["cms_score"], reverse=True)
        winner = candidates[0]
        payload = {
            "status": "ACTIVE_SIGNAL",
            "timestamp": datetime.utcnow().isoformat(),
            "winner": winner,
            "all_qualified_count": len(candidates)
        }

    with open(out_file, "w") as f:
        json.dump(payload, f, indent=2)

    print(json.dumps(payload, indent=2))

if __name__ == "__main__":
    main()

```

#### 3. `.github/workflows/run_screener.yml`

```yaml
name: Weekly NSE Momentum Screener

on:
  schedule:
    # Runs every Friday at 10:30 AM UTC = 4:00 PM IST (post-market close)
    - cron: '30 10 * * 5'
  workflow_dispatch: # Allows manual trigger from your phone via GitHub mobile app

jobs:
  screen:
    runs-on: ubuntu-latest

    steps:
      - name: Checkout Repository
        uses: actions/checkout@v4

      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: '3.11'
          cache: 'pip'

      - name: Install Dependencies
        run: pip install -r requirements.txt

      - name: Run Screener Engine
        env:
          CAPITAL_BASE: '1000.0'
        run: python src/engine.py

      - name: Commit and Push Latest Signal
        run: |
          git config --local user.email "action@github.com"
          git config --local user.name "GitHub Action"
          git add data/signals/latest.json
          git commit -m "chore: update momentum signal [$(date -u +'%Y-%m-%d')]" || echo "No changes to commit"
          git push

```

```markdown
# Quantitative Architecture Review: Small-Capital Disciplined Trend-Following Engine

## 1. Context & Operational Constraints
- Target Market: Indian Equities (NSE Cash Delivery / CNC).
- Capital Base: ₹1,000 (starting unit, compounded cumulatively).
- Platform: Zerodha Kite (Execution via GTT - Good Till Triggered).
- Hardware / User Constraints: User operates exclusively via mobile phone (no permanent PC/terminal). 
- Frequency: Weekly evaluation (Friday 16:00 IST close) to eliminate intraday screen-time.

## 2. Key Structural Trade-Offs & Math
- Depository Friction Problem: Sells in Indian cash delivery incur a flat DP charge of ~₹18.50 + 18% GST (approx ₹22 per scrip per day). 
  - On a ₹1,000 position, a +2.5% intraday scalp gain (+₹25) is virtually eliminated by fees (net +₹3).
  - Solution: Rejection of intraday scalping. Positions are held over multi-week trends targeting +15% (M1) and +30% (M2), where fixed DP charges drop to < 7% of gross profits.
  - Allocation: Single-instrument allocation (100% into Rank #1). Splitting ₹1,000 across multiple stocks doubles the DP fee.

## 3. Screening & Filtration Architecture
- Price Range: ₹100 <= CMP <= ₹950 (ensures full unit allocation with ₹1,000).
- Liquidity Floor: 20-day Average Volume >= 500,000 shares (prevents circuit-locked illiquid traps).
- Anti-Downfall Filters:
  - CMP > 50-day SMA > 200-day SMA (Stage 2 trend confirmation).
  - 1-Month (20-day) ROC > 0% AND 2-Month (40-day) ROC > 0% (hard disqualification of stocks in a 2-month bleed).
  - Proximity to 52-Week High: (CMP - 52W High) / 52W High >= -0.15.
- Composite Momentum Score (CMS) for Ranking:
  CMS = (0.50 * 3-Month ROC) + (0.30 * 52-Week Proximity) + (0.20 * Volume Ratio)
  Rank #1 gets 100% capital allocation.

## 4. Execution & Dynamic Ratchet (Zerodha GTT)
- Initial Risk: Hard stop at -7.0% from entry.
- Milestone 1 (+15% Gain): Stop moves to Entry + 2.5% (Risk-free break-even floor covering all round-trip taxes and DP charges).
- Milestone 2 (+30% Gain): Stop moves to Entry + 15.0% (Hard lock of 50% of peak gains).
- Milestone 3 (+50% Gain): Trailing Stop via 20-DMA or 2x ATR.

## 5. Automation Stack
- Engine: Python 3.11 with pandas, numpy, and yfinance.
- Orchestration: GitHub Actions cron workflow running every Friday at 16:00 IST.
- Output: Committed `latest.json` on GitHub and mobile webhook notification.

## Questions for Reviewing AI:
1. Are there edge cases in the anti-downfall filter where a high-beta stock with a short-term shakeout is prematurely filtered or mistakenly included?
2. How can we further optimize the Composite Momentum Score (CMS) weighting without overfitting historical data?
3. What is the most cost-effective, zero-server way to push an instant alert directly to an Android phone when `latest.json` updates on Friday?

```
